## 📌 Project Overview

This project is an **interactive Hotel Management Dashboard** built in **Microsoft Excel** to analyze hotel booking data from **2015–2017**.

The dashboard transforms raw booking data into meaningful business insights using **Power Query**, **Pivot Tables**, **Pivot Charts**, **KPI Cards**, **Slicers**, and **Timeline Filters**.

It enables users to explore booking trends, cancellation patterns, hotel performance, customer behavior, and room allocation interactively.

# 📊 Key Performance Indicators (KPIs)

The dashboard includes the following KPIs:

- 📌 Total Bookings
- ❌ Cancellation Rate
- 💰 Average ADR (Average Daily Rate)
- 🛏 Desired Room Percentage
- 👨‍👩‍👧 Total Guests

---

# 📈 Dashboard Visualizations

The dashboard contains multiple interactive charts:

- 📈 Monthly Booking Trend
- 🏨 Hotel-wise Bookings
- 📊 Market Segment Analysis
- ❌ Cancellation by Market Segment
- 🛏 Room Status Distribution
- 👨‍👩‍👧 Family Status Distribution

---

# 🎛 Interactive Features

Users can dynamically filter the dashboard using:

- Hotel
- Customer Type
- Market Segment
- Room Status
- Family Status
- Arrival Date Timeline

All charts and KPIs update automatically based on the selected filters.

# 🧹 Data Preparation

Data cleaning and transformation were performed using **Power Query**.

### Tasks Performed

- Imported raw hotel booking dataset
- Removed invalid guest records
- Created **Room Status** calculated column
- Created **Family Status** calculated column
- Cleaned inconsistent data
- Prepared data for Pivot Tables

# 🚀 How to Use

1. Download the Excel workbook.
2. Open it in **Microsoft Excel 2016 or later**.
3. Enable editing if prompted.
4. Use the slicers and timeline to interact with the dashboard.
5. Click **Data → Refresh All** if the data source is updated.
